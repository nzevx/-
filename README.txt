A LITTLE UNIVERSE MADE FOR YOMNA — DREAMY FAIRYTALE EDITION

A small interactive storybook surprise, enhanced with a moonflower garden, an original browser-generated melody, glowing meteor keepsakes, and a secret room.

HOW TO OPEN IN ACODE
1. Extract this ZIP into a folder named A-Little-Universe.
2. Open the extracted folder in Acode.
3. Open index.html and use Preview / Open in browser.
4. Keep index.html, style.css, theme.css, and script.js in the same folder.
5. Clouds, flowers, sparkles, the music box, secret door, and treasure chest are CSS-drawn; no image assets are required.
6. Google Fonts are loaded online. If offline, the site falls back to system fonts.
7. The melody is generated in the browser and starts only when the music button is tapped. Some browsers require a tap before audio can play. It can be paused any time.
8. The reduce-motion control remains available in the top bar.

THE NEW STORY FLOW
1. Enter the original little universe.
2. Visit the Moonflower Garden and tap the four flowers to read their messages.
3. Visit A Melody in the Clouds and optionally play the tiny generated melody.
4. Continue to the original constellations, letter, and clue chapter.
5. In the meteor chapter, collect The Flower, The Melody, and The Meteor keepsakes. The secret-room button appears after all three are found.
6. Open the secret room and tap the treasure chest for the final surprise letter.

BEFORE SENDING
- Read the messages and adjust any wording to sound like you. Add a real shared memory if you want to make the surprise even more personal.
- Test flower messages, music, constellations, clues, secret door, treasure chest, and replay on your phone.
- For GitHub Pages, upload the contents of this folder and enable Pages from the main branch / root folder.
